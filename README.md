# poc-component

## Setup guide

1- Start by cloning the project in your chosen directory

`git clone https://github.com/MohamedSefyaniLakrizi/poc-component`

2- Run the project

```
cd poc-component
cd docs
make run
```

3- Open the project in your browser and go to component-examples page

```
http://127.0.0.1:8000/component-examples/
```
